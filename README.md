# CaseClosed

### Take on the role of a detective. Solve mysteries and uncover secrets.

### NOTICE!
This repository contains only part of the project source. It doesn't
include visual assets. This is because GitHub doesn't let me upload
large files. The code though is available.

## Important for playing
The game is absolutely not finished! It is in PRE-ALPHA stage.

## I am stuck!
If you click to investigate a location there isnt a clear way to
go back to the board. Just press ```TAB``` to go back.

## Installation
- Download the zip file from this link: https://github.com/k-preslav/CaseClosed-projectFiles/releases/download/Pre-Release/Case.Closed.-.Detectives.Academy.zip
- Extract the zip file and run ```Case Closed - Detectives Academy.exe```
- That's it!
